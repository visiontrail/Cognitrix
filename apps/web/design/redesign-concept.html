Interaction principles

1
One focal command surface

The composer is the hero, not a thin bar. Empty state = invitation + suggested queries; every screen makes "ask" the obvious next move.

2
Answers are reports, not bubbles

Each result pairs a one-line takeaway, a titled chart card, and an "Insight + next question" footer — with a single primary action: add to canvas.

3
Modes as a segmented control

Chat / Canvas / Split / Tables collapse into one labelled segmented control instead of a 4-icon grid — clearer affordance, same shortcuts (⌘1–4).

4
Quiet until it matters

Neutral by default; terracotta and forest reserved for state, action, and insight. Motion limited to a single staggered reveal per turn.
